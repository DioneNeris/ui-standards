# UI Standards

Open-source-intended framework for consistent, accessible and usable administrative and operational web interfaces.

**Current state:** G1 v0.1.1 documentary baseline homologated by the PO with controlled caveats; G2 technical discovery open. The imported G1 candidate originals are on `g2/bootstrap-framework`, **not** merged into `main`. The authoritative source-package integrity is **not independently verified**. No skills are implemented, no interface tests have been executed, and no product WCAG conformity is claimed.
