---
name: ui-audit
description: Use when auditing an interface against UI Standards G1 with a read-only scope.
---

Read the shared instructions and V1 contract in the package root. Read-only means no product, environment, data, infrastructure or baseline changes. Interactive or functional actions that modify state require separate authorization and are outside this audit. If read-only cannot be enforced, stop. Produce results per applicable rule and method with evidence and missing coverage. Write a report only when its exact destination is explicitly authorized; otherwise respond inline. Validate structured output before presenting it.
