description: Use when planning or implementing an authorized administrative web interface against UI Standards G1.
---

Read the shared instructions and the V1 contract in the package root. Identify scope, baseline, applicable rules, methods and constraints. Planning does not modify product files. Implement only with explicit task-scoped authorization, verified paths and safe permissions; never alter business rules, dependencies, infrastructure or norms without separate authorization. Record decisions, changes, actual checks, missing methods and evidence. Validate the structured output before presenting it.
